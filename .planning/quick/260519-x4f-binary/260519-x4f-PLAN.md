# Quick Task 260519-x4f: 优化图生视频 Binary 文案、查询默认下载视频并自动下载尾帧图

## Goal

完成三个小范围行为调整：

1. 在首帧图生视频、首尾帧图生视频两种模式下，将首帧/尾帧图片输入方式里的 `binary` 选项名称从“二进制数据”改为“Binary文件”。
2. 查询任务操作中，`下载视频` 开关默认打开。
3. 查询任务等待成功后，若返回 `lastFrameUrl`，自动下载尾帧图并附加到 binary 输出；视频仍受 `下载视频` 开关控制。

## Implementation Plan

- Update `nodes/Seedance/description/create.operation.ts` first/last frame input option labels only.
- Update `nodes/Seedance/description/get.operation.ts` so `downloadVideo.default` is `true`.
- Extend `nodes/Seedance/shared/transport/request.ts` with a generic image download helper that follows existing video download safety settings and error normalization.
- Update `nodes/Seedance/Seedance.node.ts` get/wait success handling to attach `binary.lastFrame` whenever a non-empty `lastFrameUrl` is present.
- Add/adjust tests in `test/seedanceGetWaitMode.test.ts` and `test/seedanceDownloadFlow.test.ts`.

## Acceptance Checks

- Contract tests show the two old image-to-video binary selectors display `Binary文件`.
- Contract tests show `downloadVideo` defaults to `true`.
- Waited succeeded task with `videoUrl` and `lastFrameUrl` downloads both `binary.video` and `binary.lastFrame`.
- Waited succeeded task with `downloadVideo=false` still downloads `binary.lastFrame` when `lastFrameUrl` exists.
- Non-succeeded or missing `lastFrameUrl` does not download the tail frame.
