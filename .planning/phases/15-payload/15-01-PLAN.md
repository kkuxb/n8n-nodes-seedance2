# Plan 15-01: Build official multimodal payload mapper and validation contract

<objective>
Implement the pure shared contract for Phase 15: validate multimodal reference count/combination rules, normalize URL and asset source values, emit official Seedance 2.0 `content` objects for image/video/audio references, and expose safe request summary metadata without raw media values.
</objective>

<scope>
In scope:
- `SeedanceCreateInput` reference material contract and payload-level validation.
- Official multimodal `content` construction for `image_url`, `video_url`, and `audio_url`.
- Safe `requestSummary` additions.
- Unit tests in `test/createPayload.test.ts`.

Out of scope:
- n8n binary reading and MIME handling; handled by Plan 15-02.
- Full media format, size, duration, FPS, codec, and request-size validation; handled by Phase 16.
- Existing text-to-video, first-frame, and first/last-frame behavior changes beyond regression protection.
</scope>

<threat_model>
| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-15-01 | Raw media URLs, Base64/data URLs, binary property names, or asset IDs leak through `requestSummary`. | high | Build per-reference summaries from metadata only and add negative tests that search summary JSON for raw values. |
| T-15-02 | Invalid official combinations such as audio-only or prompt-only multimodal requests are sent to Volcengine. | medium | Add `validateCreateInput()` checks before payload construction and assert thrown Chinese error messages. |
| T-15-03 | Multimodal references accidentally use first/last-frame roles or reorder mixed media types. | medium | Add exact payload assertions for ordered mixed image/audio/video references and absence of `first_frame` / `last_frame` in multimodal payloads. |
</threat_model>
